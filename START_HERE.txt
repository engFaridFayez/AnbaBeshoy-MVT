المخزن - المرحلة الثالثة
=================================
1. خذ نسخة احتياطية من المشروع وقاعدة البيانات.
2. انسخ مجلدي accounts و store بجانب manage.py. ادمج المجلدات، لا تحذف القديمة.
3. في accounts/urls.py أضف:

from . import portal_views

وبدل مسار الرئيسية القديم:
path("", views.home, name="home"),

اكتب هذين السطرين في urlpatterns:
path("", portal_views.services_home, name="home"),
path("meals/", views.home, name="meals"),

لا تحذف مسارات login أو logout أو dashboard.
لا تعدل دالة accounts.views.home القديمة؛ ستظل صفحة الوجبات.

4. في api/urls.py أضف داخل urlpatterns قبل مسار accounts:

path("store/", include("store.web_urls")),

5. شغل:
python manage.py check
python manage.py test store.tests_web store.tests_stock
python manage.py runserver

6. افتح الرئيسية /. ستجد المطعم والمخزن.
المطعم /meals/ - المخزن /store/.

لا توجد مكتبات جديدة أو تغييرات موديلات. يلزم تركيب المرحلتين الأولى والثانية مسبقًا.
